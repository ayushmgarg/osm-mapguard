OpenStreetMap · damaging-edit detection

Which map edits get reverted?

MapGuard scores each OpenStreetMap changeset (one upload of edits) for how likely it is to be damaging. Every number below comes from the held-out test set of Ovid's 2014–2019 benchmark: changesets by authors the model never saw in training, scored by the round-4 models (mean of 3 seeds).
